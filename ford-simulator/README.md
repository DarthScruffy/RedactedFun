# Ford Simulator (fan tribute)

A from-scratch homage to the late-80s / early-90s DOS **Ford Simulator** games:
320x200 graphics in the 16-color EGA palette, a car showroom with spec sheets,
a handful of courses, a gauge-cluster dashboard and PC-speaker-style sound.

It's one self-contained file with no dependencies. **Open `index.html` in any modern browser to play.**

## Controls

| Key | Action |
| --- | --- |
| Up / W | Gas |
| Down / S / Space | Brake |
| Left, Right / A, D | Steer |
| Enter | Select |
| Esc / P | Pause / back |
| M | Sound on/off |

On phones and tablets, on-screen buttons appear under the screen.

## What's in it

- **Showroom:** 8 period cars (Mustang GT 5.0, Taurus SHO, Thunderbird Super Coupe,
  Probe GT, Escort GT, Crown Victoria, F-150, Festiva), each with its own acceleration,
  top speed, grip and gearing, plus 10 paint colors.
- **Courses:**
  - Test Track: a 3-lap oval
  - Country Road: hills, curves, farm traffic
  - Slalom: cone gates with time penalties
  - Interstate: sunset, heavy traffic
  - Night Run: headlights only
- A dashboard with a speedometer, tachometer, LCD readout and a live course map.
- Best times per course, saved in your browser.

Specs are approximate period figures. This is an unofficial fan project and isn't
affiliated with Ford Motor Company.
